# 0.10.0 界面与交互设计

本版延续 [0.9.0 的阅读与 DPI 设计](design-0.9.0.md)，针对重复说明、多层边框、翻译框移动、圆角与朗读方式作调整。设计目标是减少阅读时的干扰，保留清楚的输入、状态和可发现的操作，不增加 WebView 或主题运行时。

本文描述实现约定与验收标准，不是测试通过或已公开发行的记录。实际结果见 [构建记录](build-validation.md) 与 [Windows 清单](windows-validation.md)。旧截图、Wine 与 CI 不能证明 Windows 11 四角、Edge 跨软件取词或真实声音已经通过。

## 设置

侧栏只保留“翻译服务 / 偏好设置 / 外观”。品牌下不显示语言对和快捷键，去掉“语言偏好”“更改后立即生效”等常驻说明；字段名、必要的失败信息和保存成功弹窗仍保留。图标说明移到 tooltip 和可访问名称，明暗切换只显示太阳或月亮。

导航用背景与强调色标记状态，移除实线焦点矩形；键盘焦点仍须可辨认。模板以单层选中框与标记表达选择，避免内外两个圆角框叠加。沿用四套模板、八种明暗组合，不降低正文对比度。常规文字为 16 逻辑像素，标签为 13，工具图标与窗口图标随 DPI 重建。

设置支持拖动调整大小，最小 600 × 480 逻辑像素；内容超出时滚动，底部保存和更新入口需可达。缩小时不缩小字体，也不裁掉下拉、焦点或输入位置。服务、语言与快捷键仍显式保存；模板和明暗独立即时保存，不顺带提交其他草稿。

“朗读接口”和“图标外观”以设置页为 owner，在其上方居中。子窗口只呈现相关字段，不重复大段使用说明；关闭后恢复合理焦点与父窗口层级。

## 翻译位置与四角

首次有效翻译将窗口放在选区附近，并限制在工作区内。连续选择与重新翻译更新同一 HWND 的内容，保留首次位置；用户拖动后记录新位置。显式关闭清除定位锚点，下一次翻译重新选择初始位置。该规则同时覆盖点击图标、直接翻译、缓存命中与绕过缓存的重新翻译。

取词图标继续跟随选区；“保持窗口显示”控制失焦收起，不改变连续翻译位置规则。换选区时取消旧请求，旧响应不能覆盖新内容。空白划选不新建图标、译文或自动错误框；手动编辑时暂停自动划词，保护用户输入。

翻译外框与内容按实际矩形和 DPI 生成一致的圆角裁切，避免系统 DWM 圆角与手工区域相互冲突。阅读区背景、边界和裁切需一致，四角不能残留白块、黑块、旧像素或正文缺口。支持的 Windows 11 路径与 Windows 10 / Wine 降级分别验收，不能只由兼容层截图判断。

## 默认叶片

默认图标为 `#19A97C` 绿色叶片、白色叶脉、32 逻辑像素，叶片轮廓外透明，无阴影。新增叶片形状保留旧圆角、方形、圆形的配置编号，旧自定义颜色、尺寸和样式继续生效。

旧配置只有在缺少新默认值标记、且精确匹配“译字 / 圆角 / `#D6A575` / 32”时，才在内存中采用新默认。读取不保存配置，已有标记或其他自定义不迁移；用户显式应用后才按正常保存流程写入。

## 手动输入

默认 Ctrl+Alt+Space 打开原文编辑区，可粘贴、编辑后点击“翻译”或按 Ctrl+Enter；普通 Enter 换行。Ctrl+Alt+T 继续读取当前选区，两个入口用途清楚。手动快捷键在偏好设置中更改，拒绝无效或保留组合；注册冲突或配置保存失败时恢复旧绑定，避免界面显示成功而快捷键不可用。

手动编辑期间暂停自动划词，关闭后恢复原有设置与本次暂停状态，不把临时编辑写为永久总开关。原文、译文、问题草稿与旧回复时序隔离；后到的自动读取或回答不能改写手动草稿。

## 简洁润色

一次点击发一个模型请求，结合原文与现有译文，要求只返回目标语言的完整润色译文，保留事实与数字；无需修改时返回原译文。不输出检查清单、开场说明、总结或多份版本。原译文和待发送问题保留，失败 / 停止不进入成功历史，不自动重试。

润色使用当前翻译服务，可能产生一次问答费用。模拟服务可验证请求数与上下文，实际模型是否遵循格式和语义质量需单独记录。

## 在线朗读

移除本机 SAPI，采用 OpenAI 兼容 `POST /audio/speech`，请求包含 `model`、`input`、`voice` 和 `response_format: "wav"`。服务可为 OpenAI，或提供该协议的远端开源语音部署，如 Kokoro；不假设任意开源项目的原生 API 都兼容，也不内置免费托管地址。

设置在“翻译服务 → 朗读接口”独立保存地址、模型、音色与密钥；密钥单独由 DPAPI 保护，不复用或转发 DeepSeek 等翻译密钥。空地址默认不联网，点击扬声器先打开配置。HTTPS 用于远程，HTTP 仅允许 loopback；服务地址和凭据验证沿用严格约束。

只将当前可读译文发送给已配置的语音服务。响应限定为受支持的 PCM WAV，在有界内存中校验、通过 Windows 音频接口播放，不写音频文件或捆绑模型。停止、换选区和关闭取消下载或播放；旧任务不能覆盖新按钮和状态。网络错误、无效音频、超限与设备失败均应可恢复，不阻塞翻译。

真实接口兼容性、语言音色、费用及实际声音分别验收。模拟 WAV、无音频硬件和 Wine 只证明对应路径，不代表已听到远端服务发声。

## 阅读与验证边界

保留原生 RichEdit 的 Markdown 排版、选字、滚动和四项复制。HTML 按字面显示，外图不下载，链接不自动打开；超长复杂内容可保留全文并退为纯文本。减少边框与说明不能以失去键盘焦点、控件名称、错误反馈或高 DPI 清晰度为代价。

本版发布重点覆盖 600 × 480 缩放与滚动、八种配色、连续翻译位置、四角、热键冲突与回滚、旧图标迁移、TTS 独立密钥及取消、空白划选、Edge / PDF 与已有更新按钮。真实 Windows 桌面、原生 CI、Wine 和公开源下载应各自留证。
