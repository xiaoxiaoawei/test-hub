# 0.9.0 界面与阅读设计

本版将设置改为侧栏导航，重新安排文字、间距和操作层级；译文与问答加入 Markdown 排版、朗读和显式检查润色。继续使用 Rust 与原生 Win32，不引入 WebView。本文说明设计来源和实现取舍，不代表相关 Windows 实机项目已通过；结果见 [构建记录](build-validation.md)。

## 布局与外观

设置默认采用 **760 × 680 逻辑尺寸**。左侧服务 / 偏好 / 外观导航固定，右侧只显示当前页的字段和分组。常规文字以 16 逻辑像素为基准，辅助标签以 13 逻辑像素为基准，标题单独分级；说明不与输入、主要按钮争抢注意。

深海蓝、极光青、星云紫、暖砂金继续各提供暗夜和白天，共八种组合。正文、次级文字、输入底色、强调色和边界由同一模板提供；文字选区、焦点与禁用状态保留辨识度。旧配置缺少模板字段时采用暖砂金并保留原有明暗，暖砂金白天保留米黄色背景。

模板和明暗即时应用并保存，只写入外观偏好；未保存的服务、密钥、语言和划词草稿不被提交或清空。自定义划词图标不随模板重置。图标外观仍从外观页进入，子窗口以设置为 owner，在其上方居中。

输入、下拉、按钮、卡片与浮框采用一致的圆角语言，同时保留原生 Tab、下拉键盘操作、中文输入和文本选择。Windows 11 的系统外框效果、Windows 10 与 Wine 的降级分别验收；划词图标继续透明且无阴影。

## 清晰度与 DPI

常规文字由 Windows 原生文字系统绘制；译文与问答使用 RichEdit 的字体与段落布局。尺寸随所在显示器 DPI 调整，避免将整块界面作为低分辨率图片放大。

工具图标以目标物理像素为最终尺寸，通过 4 倍采样计算覆盖率后按 1:1 绘制；窗口 HICON 随窗口 DPI 重建。此举改善小尺寸曲线与斜线的边缘，实际清晰度仍应在 100%、150%、200% 和混合 DPI 显示器上观察。不能仅靠一张截图判定跨屏、文字焦点或系统图标均正常。

## Markdown 阅读与复制

原始响应仍是内容来源。`pulldown-cmark 0.13` 解析 Markdown，再生成原生 `RichEdit50W` 可读的 RTF；不使用 HTML 页面或浏览器。

| 内容 | 显示规则 |
|---|---|
| 标题、粗体、斜体、删除线 | 用字号或字形区分层次 |
| 列表、引用与任务项 | 用段落、缩进和标记组织 |
| 行内代码与围栏代码 | 等宽文字，保留代码内容 |
| 表格 | 原生表格显示，可读复制使用制表符分隔单元格 |
| 链接 | 显示标签和可见网址，不自动打开；超长网址可缩短展示，原始内容仍保留 |
| HTML、脚本、图片 | HTML 与脚本作为字面文字，不执行；不加载外部图片 |

流式尚未闭合的标记先按当前内容显示，后续更新再排版。现有上翻、选字和底部跟随规则继续保留。

为约束富文本资源，超过 256 KiB、检测到超过 32 列的表格或格式展开超出预算时，保留完整源码并退为纯文本，不截断模型响应。这些是当前渲染边界，不代表服务允许无限长请求或回答。

复制按钮提供可读纯文本译文；右键菜单第四项“复制 Markdown 原文”保留本轮内容的原始标记。原生选区与 Ctrl+C 保留，复制结果从内容来源或当前选区取得，不通过富文本画面猜测 Markdown。

## 朗读与检查润色

**朗读**用于听取已经完成的当前译文，先移除 Markdown 排版标记，再交给本机 Windows SAPI，匹配当前目标语言的已安装语音。再次点击停止，换选区取消旧朗读；缺少相应语音时提示。音频工作在线程中运行，不占用翻译 API，也不下载额外语音模型。真实发声、声音语言和设备必须在有音频的 Windows 环境验证。

**检查与润色**是一次显式模型操作。点击后结合当前原文、译文和必要的成功问答上下文，请当前配置模型检查准确性、遗漏、术语和表达，使用目标语言给出检查要点与润色后的完整译文。结果显示在本轮会话，原译文与正在编辑的问题草稿保留，可继续追问或停止。

润色不自动运行、不循环请求，也不使用翻译缓存；每次显式执行会产生一次问答请求，可能消耗服务额度。结果取决于模型，不将检查完成视为准确性保证。本机朗读与模型润色的网络和费用边界分别说明，避免混淆。
