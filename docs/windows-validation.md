# Windows 手工验证

本清单用于原生交互和真实服务验收。它不是已通过记录；每次验证应记录日期、提交 SHA、Windows 版本、CPU 架构、缩放、软件版本和实际结果。未执行、通过、失败与不适用应分别记录。

0.4.1 的连续划词和 Chrome、Edge 文本 PDF 项目仍待 Windows 实机验收。现有 0.4.0 截图仅展示旧版外观，不能用于勾选本版项目；Linux 构建、单元测试和 Wine 回归也不能代替真实浏览器验收。

可先在可交互桌面运行 `cargo run --locked --example ui_smoke -- target\release\lingoleaf.exe`，自动检查首次启动顶层焦点下的空闲 CPU、服务预设及基本控件。它不调用真实翻译接口，不能替代下列跨软件和多屏验收。

## 浏览器文本 PDF 专项

在 Windows 上分别使用当前 Chrome 和 Edge 的内置 PDF 阅读器，按下表在默认点击模式、直接显示模式各执行一遍。至少准备一份可选择文字的短 PDF 和一份多页长 PDF，并记录浏览器版本、文档页数、缩放及本地文件或网页来源；不使用含个人信息的文档。浏览器或文档未暴露真实选区时，记录受限情况，不将复制可用、整页文字或其他控件的旧选区当作成功。

实现采用命中文档子树、真实选区范围与本次手势位置核对，结合在后台预热当前前台文档、选区通知和有界延迟重试。专项验证必须确认实际效果及耗时，不能据此宣称所有网页或 PDF 均支持。自动流程只读选区，不触发 Ctrl + C；可提前放入无敏感内容的剪贴板标记，逐项核对其未改变。
