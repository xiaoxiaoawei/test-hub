# Windows 手工验证

本清单用于原生交互和真实服务验收。它不是已通过记录；每次验证应记录日期、提交 SHA、Windows 版本、CPU 架构、缩放、软件版本和实际结果。未执行、通过、失败与不适用应分别记录。

0.10.2 追加验证本机诊断、真实 hook → 控制器 → 取词 → 渲染、显示测试零请求与复制报告隐私；0.10.1 继续验证手动框最小化后的自动恢复、监听线程隔离 / 失配恢复和延迟选区重试；0.10.0 继续验证精简设置与拖动缩放、连续翻译与重译位置、四角裁切、手动快捷键、绿叶默认迁移、独立在线朗读及简洁润色；继续回归 Markdown、八种配色、停止 / 重译、问答、阅读位置、保持显示、暂停、语言、取词、剪贴板、保存和更新。下表是待执行清单，实际结果以 [构建记录](build-validation.md) 为准。旧截图、Wine 兼容层和原生 Windows CI 不代替真实 Windows / Edge 桌面验收；公开 latest 清单与实际下载也须分别核验。

可先在可交互桌面运行 `cargo run --locked --example ui_smoke -- target\release\lingoleaf.exe`，自动检查首次启动顶层焦点下的空闲 CPU、服务预设及基本控件。它不调用真实翻译接口，不能替代下列跨软件和多屏验收。
