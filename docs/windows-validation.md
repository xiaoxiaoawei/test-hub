# Windows 手工验证

本清单用于原生交互和真实服务验收。它不是已通过记录；每次验证应记录日期、提交 SHA、Windows 版本、CPU 架构、缩放、软件版本和实际结果。未执行、通过、失败与不适用应分别记录。

可先在可交互桌面运行 `cargo run --locked --example ui_smoke -- target\release\lingoleaf.exe`，自动检查首次启动顶层焦点下的空闲 CPU、服务预设及基本控件。它不调用真实翻译接口，不能替代下列跨软件和多屏验收。

额外边界：

- 密码框：不读取或上传内容。
- 普通权限程序与管理员程序：受限时清楚反馈，不自行提权。
- 扫描 PDF、图片、画布、远程桌面内容：不能读取时按不支持处理，不生成虚假的成功结果。
- 超长选区：有限制并提示，不无界占用内存或发送请求。
- 焦点仍在工具栏、侧栏或其他控件时选中正文：可读取时使用鼠标位置对应的真实选区，不把焦点控件的整段内容当作选区。
- 控件更新选区较慢：有限重试后得到真实选区；最终无法读取时停止，不持续轮询或显示上一次选区。
